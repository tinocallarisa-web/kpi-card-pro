KPI CARD PRO — TIPS & HINTS (versión para pegar)
================================================================
Los text boxes de Power BI no soportan tablas markdown: al pegar se pierde
el formato. Esta versión usa listas con puntos guía, que sobreviven al
copiar y pegar. Un bloque por text box.


TEXT BOX 1 — Título de página
----------------------------------------------------------------
KPI Card Pro — How to use this visual


TEXT BOX 2 — Getting Started
----------------------------------------------------------------
GETTING STARTED

1. Add KPI Card Pro to your report page.
2. Drag a measure to the Value field well — the card renders immediately.
3. Optionally add a Prior Period measure to see variance vs. previous period.
4. Optionally add a Target measure to display target tracking, and switch
   on Status (Pro) to colour the card on track, warning or off track.
5. Add a date to Trend (Pro) and the card grows a trend line.
6. Use a dimension field in Small Multiples (Pro) to split into multiple
   cards, each with its own line.
7. Add up to three measures to Secondary KPIs (Pro) and they appear beside
   the main value, each with its own variance.
8. Bind a Base64 image column to Image to show a logo on each card.


TEXT BOX 3 — Field Wells
----------------------------------------------------------------
FIELD WELLS

Value (required) ......... The main KPI measure. Total Sales, Revenue,
                           Headcount.
Prior Period (optional) .. A measure for the previous period. The visual
                           calculates the variance. See "No date table, no
                           DAX" below — with Trend bound you may not need it.
Target (optional) ........ A budget or target measure, shown below the value.
Trend (Pro) .............. A date or ordered period. Draws the trend line
                           inside each card, and feeds the comparison modes.
Secondary KPIs (Pro) ..... Up to 3 supporting measures, stacked to the right
                           of the main value. Margin %, Orders, Avg ticket.
Secondary KPIs prior (Pro) Their comparison values, MATCHED BY POSITION: the
                           first here pairs with the first Secondary KPI.
                           Optional — with Trend bound the visual works it
                           out from the series.
Image (optional) ......... A column with a Base64 data URI
                           (data:image/png;base64,...), shown top-right.
                           Set the aggregation to First. External URLs are
                           rejected.
Small Multiples (Pro) .... A category dimension. One card per value, up to 50.
Tooltips (Pro) ........... Additional measures shown on hover.


TEXT BOX 4 — No date table, no DAX
----------------------------------------------------------------
NO DATE TABLE, NO DAX

Comparing against the previous period normally means a date table marked as
such, DATEADD, and one measure per KPI. With a date field in Trend, the card
reads the comparison off the series it already draws.

Format pane > Value & comparison > Value shows:

  Total of the period .... The whole range. The default, unchanged.
  Latest point in Trend .. The last point of the series, compared against an
                           earlier one. "Compare against (points back)" = 1
                           is the previous point; 12 on a monthly series is
                           the same month last year.
  Last N points .......... The last N summed, against the N before them.
                           "Window size" = 12 on a monthly series is the
                           rolling year against the previous one, and the
                           sparkline keeps every point.

The card prints what it is comparing — "Dec 2025 vs Nov 2025". Read it: the
visual steps back a POSITION in the series, not a calendar step. Twelve back
is twelve months only if the series is regular; with a month missing it is
not, and the label is what tells you.

Two conditions, both about the data and neither about formulas:
- The Trend field must be a date or a number. Text like "Jan, Feb" cannot be
  ordered, and the visual cannot tell that the order is wrong.
- There must be at least two points. With one there is nothing to compare
  and no variance is drawn — no invented 0%.

A Prior Period measure of your own always wins when it is bound. Nothing
changes for a report that already has one.


TEXT BOX 5 — Format Pane
----------------------------------------------------------------
FORMAT PANE — QUICK REFERENCE

Card ................. Background, border colour. Pro: border width, radius,
                       padding, drop shadow.
Main Value ........... Font family, size, bold, colour, display units
                       (Auto / K / M / B), decimals. The number keeps the
                       format of the measure in your model; decimals apply
                       only once you change them. Pro: prefix, suffix.
Label (single card) .. Show, font family, size, bold, colour. Governs the name
                       above the number WHEN THERE IS ONE CARD; with Small
                       Multiples that text is governed by that card.
Variance ............. Show, invert logic, show arrow, font size. Pro: pill
                       style and the positive / negative / neutral colours.
Status (Pro) ......... Compare with target or prior period, lower and
                       upper threshold (90% / 100%), lower is better, the
                       three colours, apply to value / accent bar / both,
                       status text.
Prior & Target ....... Show, font family, size and colour of the
                       "Prior:" / "Target:" line.
Value & comparison ... What the big number shows: total, latest point or last
                       N points. Window size, points back, period label.
Secondary KPIs (Pro) . Show, position (Auto / Right / Bottom), min width
                       beside value, show variance, text sizes and colours.
                       Below the value they go in a row or a list, whichever
                       fits, the same on every card.
Trend (Pro) .......... Show, chart type (area / line / bar), colour, line
                       width, area opacity, height, last-point marker, target
                       line and its colour.
Image ................ Show, height, corner radius.
Small Multiples (Pro)  Columns (1–6), gap, category title with font, size,
                       bold and colour.
Accessibility ........ High contrast, ARIA title for screen readers.


TEXT BOX 6 — Free vs Pro
----------------------------------------------------------------
FREE VS PRO

The card is complete without a licence. Settings that need one say (Pro).

Free:
- Single KPI card with value, prior-period variance and target
- Your model's number formats, display units, decimals, label, card
  background and border colour
- Invert logic and the direction arrow
- Image per card
- Native and modern tooltips, cross-filtering, bookmarks, context menu
- Keyboard navigation and high contrast

Pro:
- Status: on track, warning or off track against target or prior period
- The trend line inside the card, with the target drawn period by period
  and the value of any period on hover
- Small Multiples: one card per category, up to 50, each with its own line
- Multi-column layout with category titles
- Secondary KPIs: up to three supporting measures with their own variance
- The Latest point and Last N points comparison modes
- Prefix and suffix on the main value
- Variance pill style and its positive / negative / neutral colours
- Extra measures in tooltips
- Card border width, radius, padding and drop shadow

TRY PRO BEFORE YOU BUY

While you are editing a report WITHOUT a licence, a Pro feature you turn on
is drawn WORKING, under a "Pro preview" watermark that names it, and Power
BI shows its own notice with the Upgrade option. Turn it off and the
watermark goes with it.

In READING VIEW — and anywhere Power BI cannot check licences, such as
Publish to Web, embedding or export — the free result is drawn with no
watermark and no prompt, so a published report never uses a feature you have
not paid for. The preview applies only to the setting you actually changed,
not to every Pro option at once.

TEXT BOX 7 — Tips
----------------------------------------------------------------
TIPS & BEST PRACTICES

- Use Auto display units to handle values from hundreds to billions without
  configuring anything.
- For cost or effort metrics where a decrease is good, enable Invert (Lower
  is Better) under Variance.
- In Trend, use a real date column. A month stored as text would be ordered
  alphabetically and the line would mean nothing — and so would the
  comparison modes, which read that same order.
- The target line is drawn period by period, so it follows a target that
  changes over time.
- In Small Multiples, set columns to match the number of categories for a
  clean row layout.
- Secondary KPIs follow the same period as the main value. A card showing
  December at the top and two years down the side would be comparing two
  different things.
- Ratios need a measure, not a column. A "Margin %" stored per row is summed
  by default and the total is nonsense. Store the components and write
  Margin % = DIVIDE(SUM(Margin), SUM(Revenue)).
- When a secondary KPI is itself a percentage, its variance is relative:
  30.5% against 30.4% reads as +0.55%, not +0.1 pp. If you want percentage
  points, leave its prior empty and add the difference as its own measure:
  Margin % delta = [Margin %] - [Margin % LM].
- Format the measure in the model (currency, percentage, decimals) and the
  card follows it, in the report's language. Never put a "%" suffix on a raw
  ratio: 0.3 would read 0.3%. Keep Prefix and Suffix for text such as "pts".
- Status reads best with a target. For costs, switch on Lower is better: up
  to the lower threshold is on track.
- With many Small Multiples columns, leave Secondary KPIs on Auto: they move
  below the value and into a list instead of disappearing.
- Right-click any card for the Power BI context menu: drill-through,
  spotlight, export data.


TEXT BOX 8 — Example Configurations
----------------------------------------------------------------
EXAMPLE CONFIGURATIONS

Executive sales card:
  Value = Total Revenue | Trend = Month
  Secondary KPIs = Margin %, Orders, Avg ticket
  Value shows = Last N points, Window size = 12
  No Prior Period measure needed: the rolling year is read off the series.

Sales dashboard by region:
  Value = Total Revenue | Prior Period = Revenue LY | Target = Revenue Budget
  Trend = Date | Small Multiples = Region | Image = Region flag (Base64)

HR overview:
  Value = Headcount | Prior Period = Headcount Previous Month
  Target = Headcount Plan | Trend = Month

Finance KPI:
  Value = EBITDA (formatted as currency in the model)
  Display Units = Millions | Invert = OFF

Sales against budget, with status:
  Value = Revenue | Target = Revenue Budget | Small Multiples = Country
  Status = ON, compare with Target, thresholds 90 / 100

Cost tracking:
  Value = Total Costs | Trend = Month | Value shows = Latest point in Trend
  Invert = ON (lower is better)
