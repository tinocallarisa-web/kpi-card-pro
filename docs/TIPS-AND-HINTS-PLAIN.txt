KPI CARD PRO 2.3 — TIPS & HINTS (versión para pegar)
================================================================
Los text boxes de Power BI no soportan tablas markdown: al pegar se pierde
el formato. Esta versión usa listas con puntos guía, que sobreviven al
copiar y pegar. Un bloque por text box.


TEXT BOX 1 — Título de página
----------------------------------------------------------------
KPI Card Pro — How to use this visual


TEXT BOX 2 — Getting Started
----------------------------------------------------------------
GETTING STARTED

1. Add KPI Card Pro to your report page.
2. Drag a measure to the Value field well — the card renders immediately.
3. Follow the setup guide inside the visual: it lists the optional fields,
   ticks each one as you add it, and lets you pick a style template with
   one click. It only shows while you edit; reopen it from
   Format > Style template > Setup guide.
4. Optional fields: Prior Period (variance), Target (goal and color rules),
   Trend (Pro, a date: trend line and period comparisons), Small Multiples
   (Pro, a category: one card per item), Secondary KPIs (Pro).


TEXT BOX 3 — Field Wells
----------------------------------------------------------------
FIELD WELLS

Value (required) ......... The main KPI measure. Total Sales, Revenue,
                           Headcount.
Prior Period (optional) .. A measure for the previous period. The visual
                           calculates the variance. With Trend bound you
                           may not need it — see "No date table, no DAX".
Target (optional) ........ A budget or target, shown below the value and
                           drawn on the trend line period by period.
Trend (Pro) .............. A date or ordered period. Draws the trend line;
                           click a point to filter the report by it.
Small Multiples (Pro) .... A category. One card per member, up to 50.
Secondary KPIs (Pro) ..... Up to three supporting measures beside the value.
Image (optional) ......... A Base64 data URI (data:image/png;base64,...),
                           aggregation First. Web links are rejected.
Tooltips (Pro) ........... Extra measures shown on hover.


TEXT BOX 4 — Color rules and templates
----------------------------------------------------------------
COLOR RULES (PRO) AND STYLE TEMPLATES

- Color rules compare the value with the Target, the Prior Period or the
  value itself, with two thresholds: on track, warning, off track.
- Paint the number, an accent bar, the card background or its border.
  "Lower is better" mirrors the logic for costs and churn.
- The state is also written under the value, so it never depends on
  colour alone.
- Conditional formatting (fx, Pro) on Main value > Color and Card >
  Background color, card by card in Small Multiples. With a Trend field,
  set a gradient's Minimum and Maximum as Number.
- Style templates (free): Classic, Clean, Bold, Minimal, Soft, Midnight.
  A template only fills what you have not changed yourself.


TEXT BOX 5 — No date table, no DAX
----------------------------------------------------------------
NO DATE TABLE, NO DAX

With a date in Trend, Format > Value & comparison > Value shows:
- Total of the period — the whole range.
- Latest point — the last month against the previous one, or against the
  same month last year (Compare against = 12 on a monthly series).
- Last N points — the rolling twelve months against the twelve before.
The card prints what it compares, for example "Dec 2025 vs Nov 2025".


TEXT BOX 6 — Filtering
----------------------------------------------------------------
FILTERING

- Small Multiples: click a card to filter the page; the others dim.
- Trend: click a point of the line to filter by that period (and card).
- Ctrl+click adds, click again removes, click empty space to clear.
- Keyboard: arrow keys between cards; on the trend line, arrows move
  between points and Enter filters.


TEXT BOX 7 — Free vs Pro
----------------------------------------------------------------
FREE VS PRO

Free: value, variance with arrow and invert, target, your number formats,
images, style templates, the setup guide, the layout that adapts to the
size of the visual, format on the canvas, cross-filtering, bookmarks,
keyboard, screen readers, high contrast, 12 languages.

Pro: color rules, conditional formatting (fx) on the value colour and the
card background, the trend line and its period comparisons, Small
Multiples, Secondary KPIs, prefix and suffix, variance pill and colours,
extra tooltip measures, card border, radius, padding and shadow.

Without a licence, Pro features are drawn working in edit mode under a
"Pro preview" watermark; reading view shows the free result.


TEXT BOX 8 — Tips
----------------------------------------------------------------
TIPS & BEST PRACTICES

- Format percentages in the model (Measure tools > Format > Percentage):
  the card uses that format. Never add a "%" suffix to a raw ratio.
- Auto display units handle values from hundreds to billions.
- For costs or effort, switch on Invert (lower is better) in Variance.
- In Trend, use a real date column: a month stored as text sorts
  alphabetically.
- Small visual? The number shrinks to stay whole and the extras step
  aside — trend first. Make it taller to bring them back.
- Big visual? A single card sizes its number to fill it, until you set
  Main value > Font size.
- In format mode, click the number, the label, the trend line or the card
  to format it right there.
- Right-click a card for the Power BI context menu (drill-through, export).


TEXT BOX 9 — Example configurations
----------------------------------------------------------------
EXAMPLE CONFIGURATIONS

Sales dashboard: Value = Total Revenue | Target = Revenue Budget |
Trend = Date | Small Multiples = Region | Color rules on Target, background.

HR overview: Value = Headcount | Prior Period = Headcount previous month |
Target = Headcount plan.

Cost tracking: Value = Total Costs | Trend = Date | Value shows = Latest
point | Invert = ON | Color rules: Lower is better.
