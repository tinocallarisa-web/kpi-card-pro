Getting started

KPI Card Pro needs one measure in the Value field well. That alone renders a single card with the value, in the format your model gives that measure. Everything else is optional:

  • Add a measure to Prior Period to show the variance, as a percentage with a direction arrow and the prior value underneath.
  • Add a measure to Target to track against a goal — and switch on Status (Pro) to colour the card on track, warning or off track.
  • Add a date to Trend (Pro) to draw a trend line inside the card. With a trend bound, the card can also compare periods by itself, with no date table and no DAX.
  • Add a category field to Small Multiples (Pro) to render one card per category — each with its own number, variance and line.
  • Add up to three measures to Secondary KPIs (Pro) to show supporting figures beside the main value.
  • Add a Base64 image column to Image to show a logo or flag per card.
  • Add measures to Tooltips (Pro) to show more figures on hover.

Field wells

  • Value (measure, required) — the number on the card.
  • Prior Period (measure) — the comparison value. Enables the variance percentage, its arrow and the “Prior:” line.
  • Target (measure) — a goal to compare against, shown on the card and drawn on the trend line period by period.
  • Image (measure, aggregated as First) — a column holding a Base64 data URI (data:image/png;base64,…), shown in the top-right of each card. External URLs are rejected: the visual makes no network requests of any kind.
  • Small Multiples (Pro) (grouping) — one card per category, up to 50.
  • Trend (Pro) (grouping) — a date or ordered period. Each distinct value is a point on the line. Use a real date column: a month stored as text would be ordered alphabetically. A numeric period is reordered by the visual so the line reads left to right.
  • Tooltips (Pro) (measures) — additional figures shown on hover.
  • Secondary KPIs (Pro) (measures, up to 3) — supporting figures beside the main value, each with its own variance.
  • Secondary KPIs prior (Pro) (measures) — the comparison value for each secondary KPI, paired by position: the first prior goes with the first KPI.

Number formats

Every figure on the card — value, prior, target, variance, secondary KPIs and tooltip fields — uses the format string of its own measure in your model and the language of the report: currency symbol, percentage, thousands separator and decimal mark. A measure formatted as 0.00% holding 0.3 is shown as 30.00%.

  • Display Units scale on top of that format: Auto picks K, M or bn; you can also force thousands, millions or billions, or none. A percentage is never scaled.
  • Decimal Places applies only once you change it. Until then the decimals come from the measure’s format.
  • A measure with a dynamic format string (a format chosen by DAX row by row) is shown with the format Power BI sends for each value, when it sends one.
  • Prefix and Suffix (Pro) add free text around the value. With a proper format in the model you rarely need them; never use the suffix “%” on a raw ratio — format the measure as a percentage instead.

Status (Pro)

Status compares the value with the target or with the prior period, as a percentage, and gives each card one of three states.

  • With the default thresholds of 90% and 100%: 100% or more is on track, from 90% to 100% is warning, and below 90% is off track.
  • Lower is better mirrors it for costs, defects or churn: up to the lower threshold is on track, up to the upper one is warning, above it is off track.
  • Apply color to the value, to an accent bar on the left of the card, or to both. The three colours are configurable.
  • Show status text writes the state under the value — “● On track · 103.1% of target” — so the meaning never depends on colour alone. In high contrast only the text is shown. The tooltip includes the status too.
  • A card with no target (or no prior period, depending on the comparison) shows no status.

Comparing periods without DAX

With a date in Trend, Value & comparison → Value shows chooses what the big number is:

  • Total of the period — the whole range (default).
  • Latest point — the last point of the series, compared with the one Compare against (points back) earlier: 1 for the previous month on a monthly series, 12 for the same month last year.
  • Last N points — the sum of the last N points against the N before them: on a monthly series, N = 12 is the rolling year against the previous one.

Show period label prints what is compared, for example “Dec 2025 vs Nov 2025”. The visual steps back by positions in the series, so a step of 12 is a year only if the series is monthly — the label is how you check it. A Prior Period measure you bind yourself always takes precedence.

Secondary KPIs (Pro)

Up to three supporting measures with their own variance. Position decides where they go:

  • Right — a column beside the value, numbers right-aligned and every variance pill at the same position. Below Min width beside value the column is withdrawn, so the main value is never squeezed.
  • Bottom — below the value: in a row when the figures fit, otherwise in a list, one line per KPI, or name above number and pill on very narrow cards.
  • Auto (default) — on the right when there is room, below when the card is narrower than the minimum width.

In small multiples every card uses the same layout: if one card needs the list, all of them show it. The grid never scrolls sideways; when the cards need more height it scrolls vertically.

Format pane

Settings and cards that need a licence carry (Pro) in their name.

  • Card — Background, Border Colour, and (Pro) Border Width, Border Radius, Padding, Drop Shadow.
  • Main Value — Font family, size, bold, colour, display units, decimal places, and (Pro) Prefix and Suffix.
  • Label (single card) — Show, font family, size, bold, colour. Governs the text above the number when there is a single card; with Small Multiples that text is governed by the Small Multiples card.
  • Variance — Show, invert logic (lower is better), show arrow, font size, and (Pro) positive / negative / neutral colours and Show as Pill.
  • Status (Pro) — Show, compare value with (target or prior period), lower and upper threshold, lower is better, the three colours, apply color to, show status text.
  • Prior & Target — Show, font family, size and colour of the “Prior:” and “Target:” line.
  • Value & comparison — Value shows, window size, compare against (points back), show period label.
  • Secondary KPIs (Pro) — Show, position, min width beside value, show variance, value and label text size and colour.
  • Image — Show, height, corner radius.
  • Trend (Pro) — Show, chart type (area, line or bar), colour, line width, area opacity, height, last-point marker, and the target line with its colour. Hover the line to read the value of any period.
  • Small Multiples (Pro) — Columns, gap, and the category title with its font family, size, bold and colour.
  • Accessibility — High contrast handling and the visual title announced to screen readers.

Free vs Pro

The card is complete without a licence. A Pro subscription adds context around it.

  • Free — one KPI card with value, prior-period variance with its arrow and invert logic, and target; your model’s number formats, display units and decimals; label styling; card background and border colour; images; native and modern tooltips; cross-filtering, cross-highlighting and bookmarks; keyboard navigation, screen-reader labels and high contrast.
  • Pro — Status colours; the trend line, with its target and hover values, and the period comparisons it enables; Small Multiples, up to 50 cards in one to six columns; Secondary KPIs; prefix and suffix; the variance pill and custom variance colours; extra measures in tooltips; and the card border width, radius, padding and shadow.

See it before you buy. While you edit a report without a licence, every Pro feature you turn on is drawn working under a “Pro preview” watermark that names it, and Power BI shows its own licence notification with the way to buy. Reading view shows the free result with no watermark, so a published report never uses a feature that has not been paid for.

Accessibility

  • Each card is reachable with Tab and selected with Enter or Space.
  • Right-click opens the standard Power BI context menu, on a card and on empty space.
  • High-contrast themes are honoured: colours follow the Power BI palette, and Status is shown as text rather than colour.
  • Cards carry ARIA labels announcing the metric name, value, variance and status. The visual title announced to screen readers is configurable under Accessibility.

Frequently asked questions

My percentage shows as 0.3.
The card uses the format of the measure in your model. Format the measure as a percentage (Measure tools → Format → Percentage) and the card shows 30%. Do not add a “%” suffix to a raw ratio: it would read 0.3%.

The card shows a different number of decimals from my measure.
Check Main Value → Decimal Places: once you change it, it overrides the measure’s format. With display units (K, M) the decimals are chosen to fit the scaled number.

The status does not appear.
Status needs Show on, a target (or a prior period, if you compare with it) and a licence — or edit mode, where it is drawn under the Pro preview watermark.

My secondary KPIs moved below the value, or disappeared.
With Position: Auto they move below when the card is narrower than Min width beside value, and they switch to a list when the figures do not fit in a row. With Position: Right they are withdrawn below that width instead. Lower the minimum width, use fewer Small Multiples columns, or choose Bottom.

My image does not appear.
The Image well only accepts Base64 data URIs (data:image/png;base64,…). A link to an image on a web server is rejected on purpose: honouring it would make the visual fetch from the network, which it never does. Convert the images in Power Query or with a small script, and set the field’s aggregation to First.

I added a field to Small Multiples and still see one card.
Small Multiples is a Pro feature. Without a licence it is drawn working only in edit mode, under the Pro preview watermark; in reading view the first category renders and Power BI shows its licence notification.

I bought Pro but the Pro features do not appear.
Licence validation runs asynchronously after the card first paints, so for a moment the free result is shown. It re-renders with your settings a second later. If it persists, confirm you are signed in with the account that holds the licence, and that it is active in the Microsoft 365 admin center.

The variance shows the wrong direction.
For metrics where lower is better — cost, defects, churn — switch on Invert under Variance, which is free. If you use Status (Pro), switch on Lower is better there too.

Does the visual send my data anywhere?
No. All calculation and rendering happens inside Power BI. The visual makes no network calls of any kind. The only host API it uses is Microsoft’s own licence check, which carries no report data. See the Privacy Policy.

Does it work in Power BI Service?
Yes. Desktop, Service and the mobile apps are all supported.
