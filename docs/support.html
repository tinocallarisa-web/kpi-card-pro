Quick Start

1. Add the visual to your report

In Power BI Desktop, go to the Visualizations pane → click the three dots → Get more visuals → search for KPI Card Pro.

2. Add a measure to Value

That alone renders a card with the number, in the format your model gives the measure.

3. Follow the setup guide

While you edit, a small panel inside the visual lists the optional fields — Prior period, Target, Trend, Small multiples — ticks each one as you add it, and then lets you pick a style template with one click. Close it with ✕ or Finish; reopen it from Format → Style template → Setup guide. It never appears in reading view.

Number formats

Every figure — value, prior, target, variance, secondary KPIs, tooltips — uses the format string of its own measure and the language of the report: currency, percentage, thousands separator, decimal mark. A measure formatted as 0.00% holding 0.3 is shown as 30.00%.

  • Display units scale on top of that format: Auto picks K, M or bn, or force one. A percentage is never scaled.
  • Decimal places applies only once you change it; until then the decimals come from the measure.
  • A measure with a dynamic format string is shown with the format Power BI sends for each value.
  • Prefix and Suffix (Pro) add free text. Never add “%” to a raw ratio — format the measure as a percentage.

Color rules (Pro)

Color rules give each card one of three states — on track, warning, off track — with your own thresholds and colours. They work on a single card and on every card of a grid. For colours driven by any field, use Power BI's conditional formatting (fx) on Main value → Color or Card → Background color (Pro), evaluated card by card in Small Multiples.

  • Compare value with: the Target (% achieved), the Prior period (% of prior), or the Value itself, with thresholds in the value's own units.
  • With the default thresholds of 90 and 100: 100 or more is on track, 90 to 100 warning, below 90 off track. Lower is better mirrors it for costs, defects or churn.
  • Apply color to: the value, an accent bar, both, the card background (a light tint, so the text stays readable) or the card border.
  • Show status text writes the state under the value — “● On track · 103.1% of target” — so the meaning never depends on colour alone. Screen readers announce it too.

Comparing periods without DAX

With a date in Trend, Value & comparison → Value shows chooses what the big number is:

  • Total of the period — the whole range (default).
  • Latest point — the last point, compared with the one Compare against (points back) earlier: 1 for the previous month on a monthly series, 12 for the same month last year.
  • Last N points — the sum of the last N points against the N before: N = 12 on a monthly series is the rolling year.

Show period label prints what is compared, for example “Dec 2025 vs Nov 2025”. A Prior Period measure you bind yourself always wins.

Secondary KPIs (Pro)

Up to three supporting measures with their own variance. Right puts them in a column beside the value, Bottom below it (in a row when they fit, otherwise a list), Auto chooses by width. In small multiples every card uses the same layout, so they stay comparable.

Style templates

Format → Style template: Classic, Clean, Bold, Minimal, Soft and Midnight. A template only fills what you have not set yourself — any colour or size you change wins. Templates are free and change colours, fonts and the size of the number; the Pro card styling (border width, radius, padding, shadow) is not part of them. On dark cards the variance colours lighten automatically to stay readable.

Selecting and filtering

  • With Small Multiples, click a card to filter the rest of the page by its category. The others dim.
  • With a Trend, click a point of the line to filter by that period — and by the card, in small multiples: March of Spain, not March of everyone. Selected points are marked with a ring.
  • Ctrl+click adds to the selection; click again to remove; click empty space to clear.
  • Bookmarks restore the selection; Edit interactions is respected; right-click opens the Power BI context menu.
  • A single card with no Trend has nothing to filter by, like Power BI's own card.

Small and narrow visuals

  • The main number shrinks to fit instead of being cut off. In a grid, all cards share the size of the one that needs it most.
  • Small Multiples Columns is a maximum: when the cards would be narrower than about 150 px, fewer columns are used.
  • When a single card is too short, the extras are withdrawn in this order: trend, prior/target line, secondary KPIs, status text, variance and label. The number always stays.

Format pane

Settings that need a licence carry (Pro) in their name. In format mode you can also click the number, the label, the variance, the trend line or the card itself to format it right there.

  • Style template — template, setup guide.
  • Card — background, border colour; (Pro) border width, radius, padding, drop shadow.
  • Main Value — font, size, bold, colour, display units, decimal places; (Pro) prefix and suffix.
  • Label — show, font, size, bold, colour.
  • Variance — show, invert (lower is better), arrow, size; (Pro) colours and pill.
  • Color rules (Pro) — compare with, thresholds, lower is better, three colours, apply to, status text.
  • Prior & Target, Value & comparison, Secondary KPIs (Pro), Image, Trend (Pro), Small Multiples (Pro), Accessibility.

The Format pane, the setup guide and the messages of the visual follow the language of Power BI: English, Spanish, French, German, Italian, Portuguese (Brazil and Portugal), Dutch, Polish, Japanese, Simplified Chinese and Korean.

Accessibility

  • Screen readers hear each card in full: name and value, period, variance against the prior, target and status.
  • Keyboard: Tab reaches the cards; arrow keys, Home and End move between them; Enter or Space selects.
  • The trend line is a slider: arrow keys move from point to point and each one is announced (“Sep: 1.39K”); Enter filters by it.
  • High contrast: system colours replace the palette and every state is also written as text.

FAQ

My percentage shows as 0.3.

The card uses the format of the measure in your model. Format the measure as a percentage (Measure tools → Format → Percentage) and the card shows 30%. Do not add a “%” suffix to a raw ratio: it would read 0.3%.

The card shows a different number of decimals from my measure.

Check Main Value → Decimal places: once you change it, it overrides the measure's format. With display units (K, M) the decimals are chosen to fit the scaled number.

Conditional formatting (fx): where does it work?

The fx button is on Main value → Color and Card → Background color (Pro): rules, gradient or field value. Power BI evaluates the rule card by card in Small Multiples. On a single card Power BI does not pass the result of a rule to custom visuals, so there use Color rules (Pro): thresholds on the target, the prior period or the value itself, applied to the number, an accent bar, the background or the border.

The number is very large, or I want a fixed size.

A single card sizes its number to the visual until you choose one yourself. Set Main value → Font size and that size is kept exactly; Reset to default brings back the automatic size. In a grid every card uses the size of the one that needs it most.

The color rules do not appear.

They need Show on, a target (or a prior period, if you compare with it — not needed for Value itself) and a licence, or edit mode, where they are drawn under the Pro preview watermark.

How do I filter the report by one month?

Bind a date to Trend and click that point of the line, or move to it with the arrow keys and press Enter. Ctrl+click adds more months; clicking empty space clears.

Clicking a single card does nothing.

A single card has no category to filter by, like Power BI's own card. Add a field to Small Multiples to filter by card, or to Trend to filter by period.

The setup guide is in the way. How do I hide it — or get it back?

Click ✕ or Finish. It only shows while you edit and never in reading view. To bring it back: Format → Style template → Setup guide.

I chose a template and some of my colours did not change.

That is on purpose: a template only fills settings you have not changed yourself. Reset a setting (the circular arrow in the Format pane) and the template's value applies.

The number got smaller, or the trend line disappeared.

The visual is smaller than the content. The number shrinks to stay whole, and on a short card the extras are withdrawn — trend first. Make the visual taller or lower Trend → Height.

My secondary KPIs moved below the value, or disappeared.

With Position: Auto they move below when the card is narrower than Min width beside value, and switch to a list when the figures do not fit in a row. With Right they are withdrawn below that width. Lower the minimum width, use fewer columns, or choose Bottom.

My image does not appear.

The Image well only accepts Base64 data URIs (data:image/png;base64,…). A link to an image on a web server is rejected on purpose: honouring it would make the visual fetch from the network, which it never does. Set the field's aggregation to First.

I added a field to Small Multiples and still see one card.

Small Multiples is a Pro feature. Without a licence it is drawn working only in edit mode, under the Pro preview watermark; in reading view the first category renders and Power BI shows its licence notification.

I bought Pro but the Pro features do not appear.

The licence is checked after the card first paints, so for a moment the free result shows; it re-renders a second later. If it persists, check you are signed in with the account that holds the licence and that it is assigned in the Microsoft 365 admin center.

The variance shows the wrong direction.

For metrics where lower is better — cost, defects, churn — switch on Variance → Invert (free), and Lower is better in Color rules if you use them.

The Format pane is in English.

It follows the language of Power BI Desktop (File → Options → Regional settings) or of the Service. Twelve languages are included; others fall back to English.

Does the visual send my data anywhere?

No. Everything is calculated and drawn inside Power BI and the visual makes no network calls of any kind. The only host API it uses is Microsoft's licence check, which carries no report data. See the Privacy Policy.

Does it work in Power BI Service and mobile?

Yes: Desktop, Service, Embedded and the mobile apps.
