>>> EMPIEZA AQUÍ >>>

A number on a dashboard is only half an answer. 9.7M in revenue — is that
good? Against target, against last month, compared with the other countries?
KPI Card Pro puts the answer on the card: the value, its variance, the target,
the trend, and now a status that says on track, warning or off track at a
glance.

And it does it without DAX. Bind your date field and the card compares the
latest month with the previous one, or the last twelve months with the twelve
before them. Bind a category and you get one card per country, product or
team, all with the same layout.

NEW IN 2.1
• Status — the value as a percentage of the target or the prior period, with
  two thresholds and three colours (on track, warning, off track). "Lower is
  better" for costs and churn. The status is also written in words, so it
  never depends on colour alone.
• Your number formats — currency, percentages, separators and the language of
  your report are taken from the measure in your model, the way native Power BI
  cards do. Display units and decimals still work on top of them.
• Secondary KPIs that rearrange themselves — beside the value, in a row or in
  a list, whichever fits, and the same on every card.
• Hover the trend line to read the value of any period.
[SOLO SI LO HAS PROBADO EN DESKTOP — si no, borra esta línea:]
• Dynamic format strings — a measure whose format changes by row (currency
  per country, % or units per KPI) is shown with its own format on each card.

FREE
The complete card: value, variance against a prior period with its arrow and
the invert logic for costs and churn, target, images, display units, your
model's number formats, cross-filtering, bookmarks, keyboard navigation and
high contrast.

PRO
Status colours, the trend line, Small Multiples — one card per category, up
to fifty —, Secondary KPIs, the comparison modes, prefix and suffix, the
variance pill and its colours, extra tooltip measures, and the card styling.

Try it before you buy: while you edit without a licence, every Pro feature
you turn on is drawn working under a "Pro preview" watermark. Reading view
shows the free result, so a published report never uses a feature you have
not paid for.

NO NETWORK ACCESS
The visual makes no HTTP requests, stores nothing and needs no companion
service. Images must already be in your model as Base64 — links to images on
a web server are rejected on purpose, which is what makes that claim true.
