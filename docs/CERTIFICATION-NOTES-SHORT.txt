PLEASE READ FIRST - PRO PREVIEW
Without a licence, IN EDIT MODE ONLY, a Pro feature the user turns on is drawn
WORKING under a "Pro preview" watermark naming it. Intentional, not missing
gating. In reading view, before the licence resolves, and where licences cannot
be read (Publish to Web, embed, export) the FREE result is drawn. Per feature.

WHAT IS NEW IN 2.1
Status (Pro): value as % of target or prior, two thresholds, three states, also
written as text. Numbers use each measure's format string and the report locale
(valueFormatter); general.formatString declared for dynamic formats. Secondary
KPIs: right, row or list, same layout on every card; grid scrolls vertically
only. Trend hover value. supportEnhancedTooltips. Exactly one renderingStarted
and one renderingFinished/Failed per update(); the licence repaint emits none.

TESTING - FREE (no licence)
1. A measure in Value: one card. Add Prior Period and Target: variance and the
   "Prior:"/"Target:" line. Click the card: it cross-filters.
2. Format the measure as a percentage in the model: the card shows it as %.
3. In EDIT mode turn on Status, bind Small Multiples or Trend, or add Secondary
   KPIs: each renders WORKING under the watermark, a banner names it, and after
   ~10 s the Upgrade bar appears. Remove it and both go.
4. Reading view: free result, no watermark, no notice.
5. Small Multiples with 6 columns: secondary KPIs move below, in a list if
   needed, the same on every card; no horizontal scroll.
6. Switch to another report page and back: the state is kept.
With an active plan the same features render clean.

PRIVACY / NETWORK
