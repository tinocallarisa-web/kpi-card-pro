Getting started

KPI Card Pro needs one measure in the Value field well. That alone renders a single card with the formatted value. Everything else is optional:

  • Add a measure to Prior Period to show the variance, as a percentage with a direction arrow and the prior value underneath.
  • Add a measure to Target to track against a goal.
  • Add a date to Trend (Pro) to draw a trend line inside the card.
  • Add a category field to Small Multiples (Pro) to render one card per category instead of one card in total — each with its own line.
  • Add a Base64 image column to Image to show a logo per card.
  • Add measures to Tooltips to show more figures on hover.

Field wells

  • Value (measure, required) — the number on the card.
  • Prior Period (measure) — the comparison value. Enables the variance percentage, its arrow and the “Prior:” line.
  • Target (measure) — a goal to compare against.
  • Small Multiples (Pro) (grouping) — one card per category, up to 50. Without a licence only the first category renders.
  • Trend (Pro) (grouping) — a date or ordered period. Each distinct value is a point on the line, with the Value measure aggregated at that point. Use a real date column: a month stored as text would be ordered alphabetically. A numeric period is reordered by the visual so the line reads left to right in time.
  • Image (measure, aggregated as First) — a column holding a Base64 data URI (data:image/png;base64,…), shown in the top-right of each card. External URLs are rejected: the visual makes no network requests of any kind.
  • Tooltips (measures) — additional figures shown on hover.

Format pane

Settings that need a licence carry (Pro) in their name.

  • Card — Background, Border Colour, and (Pro) Border Width, Border Radius, Padding, Drop Shadow.
  • Main Value — Font family, size, bold, colour, display units (Auto / K / M / B), decimal places, and (Pro) Prefix and Suffix.
  • Label (single card) — Show, font family, size, bold, colour. This governs the text above the number when there is a single card. With Small Multiples, that same text is governed by the Small Multiples card instead.
  • Variance — Show, positive / negative / neutral colours, invert logic (for cost metrics where lower is better), show arrow, font size, and (Pro) Show as Pill.
  • Trend (Pro) — Show, chart type (area, line or bar), colour, line width, area opacity, height, last-point marker, and the target line with its own colour. The target is drawn period by period, not as a flat line, so it follows a target that changes over time.
  • Image — Show, height, corner radius.
  • Prior & Target — Show, font family, size and colour of the “Prior:” and “Target:” line under the variance.
  • Small Multiples (Pro) — Columns, gap, and the category title with its font family, size, bold and colour.
  • Accessibility — High contrast handling and the visual title announced to screen readers.

Free vs Pro

The card is fully functional without a licence. A Pro subscription adds the features listed below; everything else, including all variance colours, is available to everyone.

  • Free — one KPI card with value, prior-period variance and target; display units and decimals; label styling; card background and border colour; all variance colours, invert logic and arrow; native tooltips; high contrast; keyboard focus and screen-reader labels; cross-filtering by clicking the card.
  • Pro — the trend line inside the card, over a date or period axis, with the target marked; Small Multiples, up to 50 cards from a category field, each with its own line, in a multi-column layout with category titles; prefix and suffix on the main value; the variance pill style; extra measures in tooltips; and the card border width, radius, padding and drop shadow controls.

Changing a (Pro) setting without a licence leaves the card on the free result and raises Power BI's own notification, which links to the licence. Nothing is lost: the setting is stored and applies as soon as the licence is active.

Accessibility

  • The card is reachable with Tab and selected with Enter or Space.
  • Right-click opens the standard Power BI context menu, on a card and on empty space.
  • High-contrast themes are honoured: colours follow the Power BI palette.
  • Cards carry ARIA labels announcing the metric name, value and variance. The visual title announced to screen readers is configurable under Accessibility.

Frequently asked questions

My image does not appear.
The Image well only accepts Base64 data URIs (data:image/png;base64,…). A link to an image on a web server is rejected on purpose: honouring it would make the visual fetch from the network, which it never does. Convert the images in Power Query or with a small script, and set the field's aggregation to First.

My trend line only goes down, whatever the data does.
That was a defect in versions before 1.2.0.0: a numeric period such as a month number was delivered sorted by the measure rather than in time order, so the line was the values sorted from high to low. It is fixed. If you are on an older build, use a real date column.

I added a field to Small Multiples and still see one card.
Small Multiples is a Pro feature. Without a licence the first category renders and the rest are not drawn; Power BI shows a licence notification when the field is bound.

I bought Pro but the Pro settings do nothing.
Licence validation runs asynchronously after the card first paints, so for a moment the free result is shown. It re-renders with your settings a second later. If it persists, confirm you are signed in with the account that holds the licence, and that it is active under My Account → Licenses in the Microsoft 365 admin center.

The variance shows the wrong direction.
For metrics where lower is better — cost, defects, churn — switch on Invert under Variance. This is available in both tiers.

Does the visual send my data anywhere?
No. All calculation and rendering happens inside Power BI. The visual makes no network calls of any kind. The only host API it uses is Microsoft's own licence check, which carries no report data. See the Privacy Policy.

Does it work in Power BI Service?
Yes. Desktop, Service and the mobile apps are all supported.
